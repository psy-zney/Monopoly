# PROJECT SKILLS & HELPER SCRIPTS

This directory stores reusable Agent Skills and engineering automation workflows for testing, validating, and auditing the Monopoly gameboard implementation.

## Available Skills
- `monopoly-rules-check/SKILL.md`: Audits code changes to verify compliance with Hasbro Classic Monopoly rules (mandatory auctions, rent doubling, even build rule).
- `monopoly-game-polish/SKILL.md`: Coordinates Monopoly-specific UI, BGM, SFX, gameplay feedback, and rule-safe polish for the React/Vite web game.
